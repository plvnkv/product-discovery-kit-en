# Prompt: change an approved product

---

Requested change: <description>. Analyze its impact before implementation.

Read STATE and affected requirements, design, and tasks. Create a proposed CHG with the reason, affected IDs, and impact on the user journey, MVP, budget, data, migrations, tests, and dependencies. Show which gates would become stale and which work can continue independently.

Prepare a concrete proposal for review; do not present it as already approved. After the owner's decision, update sources of truth, traceability, and tasks. Preserve IDs; mark removed requirements retired or Later with a reason. Plan only the affected rechecks. Do not start dependent implementation until the revised scope is approved.
