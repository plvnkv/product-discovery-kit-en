# Prompt: implement one task

---

Implement TASK-<number> in this product's repository. First read AGENTS.md, README.md, docs/STATE.md, and the task description. Check G3 for this wave, the baseline, and dependencies. Read related REQ/NFR, AC, UX, ADR, and active modules.

Summarize the expected behavior, boundaries, and checks. If a blocker or contradiction exists, name the specific IDs and decision needed; do not silently change scope. If there are no blockers, complete the task autonomously within the approved boundaries without asking for permission again for each local step.

Preserve other people's changes. Run relevant tests and builds, plus manual checks specified in TEST. Do not claim success without evidence. Update task status, evidence, and handoff state. Do not publish the product or perform destructive actions without appropriate authorization.

Report: outcome, changed files, covered AC, completed checks, checks not run with reasons, and known risks. If done has not been reached, honestly leave the task in review or blocked.
